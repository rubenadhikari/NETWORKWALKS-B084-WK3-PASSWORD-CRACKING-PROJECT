## Project Overview

This repository documents my Week 3 NetworkWalks Cybersecurity Internship activities focused on password cracking.

The project involved using John the Ripper (JTR), Johnny GUI, and NetworkWalks password-cracking tools to extract password hashes, recover passwords, and unlock password-protected PDF files provided for the practical exercises.

## Objectives

- Understand the basics of password hashing and password recovery.
- Learn how to use John the Ripper (JTR).
- Configure and use Johnny GUI.
- Extract password hashes from protected PDF files.
- Practice password recovery using NetworkWalks tools.
- Document practical activities with screenshots.

## Tools and Technologies Used

- John the Ripper (JTR)
- Johnny GUI
- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
- Windows 11
- Password-protected PDF practice files

## PM1 – Password Cracking Using John the Ripper (JTR)

**Folder:** `W3-PM1-Password-Cracking-JTR/`

### Activities Completed

1. Set up John the Ripper and configured Johnny GUI.
2. Extracted the password hash from the supplied PDF.
3. Loaded the hash into Johnny GUI.
4. Successfully recovered the PDF password.
5. Opened the protected PDF and verified the result.
6. Practiced the same process with two additional practice PDFs.
